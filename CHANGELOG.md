# Changelog

All notable changes to the FastIconBD eCommerce HTML template are documented here.

## [1.0.0] — 2026-11-12

### Added
- Initial open-source release of the FastIconBD eCommerce HTML template.
- 14 responsive pages: home, shop, product detail, cart, checkout, wishlist,
  login, register, about, contact, blog listing, blog post, FAQs and 404.
- Vanilla JavaScript components: hero slider, product tabs, deal-of-the-day
  countdown, quantity steppers, product gallery, FAQ accordion, grid/list
  view toggle, price range slider, toasts, scroll-reveal and back-to-top.
- Demo cart and wishlist state persisted in `localStorage`.
- Original SVG demo artwork for products, hero slides, blog covers,
  banners, avatars and the contact map.
- Comprehensive `style.css` themed through CSS custom properties.
- MIT license, README documentation and this changelog.

### Historical note
The repository dates back to April 2024, when it hosted a WordPress-powered
store. In November 2026 it was rebuilt from scratch as a dependency-free
static HTML template and open-sourced under the MIT license. The legacy
WordPress codebase, database dumps and configuration were removed from the
repository history for security before publishing.
